# DSA Teacher 🧠

> **Visual Learning for Data Structures & Algorithms**

An **interactive educational tool** that explains core data structures like arrays, stacks, and queues through **slow animations and clear mental models**. Learn HOW data structures work instead of just memorizing them.

## 🎯 Why DSA Teacher?

Learning Data Structures can be challenging:
- 😴 **Boring textbooks** - No visual reinforcement
- ❌ **Hard to visualize** - Mental models unclear
- 🤔 **Memorization trap** - Learn without understanding
- ⏱️ **Fast animations** - Can't keep up with pace
- 💻 **Code-only resources** - Not beginner-friendly

**DSA Teacher** changes this:
- 🎨 **Visual animations** - See data structure operations
- 🐢 **Slow speed** - Time to understand each step
- 💡 **Clear explanations** - Understand the "why"
- 🎯 **Interactive examples** - Learn by doing
- 📚 **Beginner-friendly** - No prerequisites needed
- ✅ **Mental models** - Build correct understanding

## 💡 Key Concepts

### Time Complexity Explained

```
O(1) - Constant Time
  Array access: arr[5]
  → Always takes same time

O(n) - Linear Time
  Array search: finding element
  → Time grows with size

O(n²) - Quadratic Time
  Nested loops, bubble sort
  → Time grows as size squared

O(log n) - Logarithmic Time
  Binary search
  → Time grows slowly

O(n log n) - Linearithmic
  Efficient sorting: merge sort, quicksort
  → Best for sorting
```

### Space Complexity Explained

```
O(1) - Constant Space
  Fixed variables
  → Same memory regardless of input

O(n) - Linear Space
  Array of size n
  → Memory scales with input

O(n²) - Quadratic Space
  2D array n×n
  → Memory scales as size squared
```

## 📚 Example Animations

### Array Insert Operation

```
Initial: [1, 2, 3, 4, 5]
Insert 99 at index 2

Step 1: Mark insertion point
  [1, 2, |3, 4, 5]  ← index 2

Step 2: Shift elements right
  [1, 2, _, 3, 4, 5]

Step 3: Place new element
  [1, 2, 99, 3, 4, 5]  ✓

Complexity: O(n) - must shift elements
```

### Stack Operations

```
Push Operation (LIFO)
  Push 1:    [1]
  Push 2:    [1, 2]
  Push 3:    [1, 2, 3]  ← Top

Pop Operation
  Pop:       [1, 2]     (removed 3)
  Pop:       [1]        (removed 2)
  Pop:       []         (removed 1)

Complexity: O(1) - constant time
```

### Queue Operations

```
Enqueue Operation (FIFO)
  Enqueue 1: [1]
  Enqueue 2: [1, 2]
  Enqueue 3: [1, 2, 3]

Dequeue Operation
  Dequeue:   [2, 3]     (removed 1)
  Dequeue:   [3]        (removed 2)
  Dequeue:   []         (removed 3)

Complexity: O(1) - constant time
```

## 💻 Code Examples

### Array Operations

```javascript
// Visualization shows each step

// Insert at index
arr.insert(index, value)  // O(n)

// Delete at index
arr.delete(index)         // O(n)

// Access element
arr[index]                // O(1)

// Search for value
arr.indexOf(value)        // O(n)
```

### Stack Operations

```javascript
// Stack - LIFO

// Add to top
stack.push(value)         // O(1)

// Remove from top
stack.pop()               // O(1)

// View top
stack.peek()              // O(1)

// Check empty
stack.isEmpty()           // O(1)
```

### Queue Operations

```javascript
// Queue - FIFO

// Add to rear
queue.enqueue(value)      // O(1)

// Remove from front
queue.dequeue()           // O(1)

// View front
queue.front()             // O(1)

// Check empty
queue.isEmpty()           // O(1)
```
